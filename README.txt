THE ELITE STAY – MANAGEMENT REPORT

Frontend-only management report demo.

Technology:
- HTML
- CSS
- JavaScript
- Bootstrap 5.3
- Bootstrap Icons

Run locally:
1. Open index.html in a browser.
2. Login with the existing demo password: admin123

The project uses frontend JavaScript objects/arrays for all sample data.
The common month selector updates Profile, Payment, Expense, Visitor and Beds data.
