THE ELITE STAY MANAGEMENT REPORT
=================================

Current Version:
Complete Frontend Management Report (Blue & White Responsive Theme)
- Admin Login (30-second session preserved)
- Common Month Filter (December 2026 – December 2027)
- Dynamic Desktop Sidebar & Mobile Fixed Bottom Navigation (Profile | Payment | Expense | More)
- Profile Management (All Profiles, Add Profile, Update Profile, Full Profile Details & Document Previews)
- Payment Management (All Payments, Add Payment, Payment History, Pending Payments, Receipt Modal, Analytics)
- Expense Management (Monthly Expense, 4-Week Weekly Expense, Daily Average Expense, Add Expense, History, Summary)
- More Module:
  - Beds Details Dashboard (Total/Occupied/Empty Beds, Occupancy %, Floor-wise, Seater-wise, Room-wise, Month-wise)
  - Visitor Enquiries Report (Preserved with Month-wise Bar Chart, Status Donut, Filters, Search & Pagination)

Technology:
- HTML5
- CSS3 (Custom Blue & White Responsive Theme)
- Vanilla JavaScript (ES6)
- Bootstrap 5.3.3 & Bootstrap Icons 1.11.3 (CDN)
